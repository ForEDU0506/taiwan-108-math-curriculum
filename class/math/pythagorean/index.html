階段 1 ‧ 核心認知與定理本質

幾何直觀與基本求邊：看見面積守恆，掌握雙向運算與雙解防呆

邊長不能直接加（$3 + 4 \neq 5$），但以三邊為邊長向外所作的「正方形面積」卻能完美相加（$9 + 16 = 25$）！

🧭 一、 核心概念與技能分析

• 幾何守恆本質： 直角三角形兩直角邊 $a, b$，斜邊 $c$。以三邊向外所圍成正方形面積滿足： $$a^2 + b^2 = c^2$$ 推廣：向外作「半圓形」或「正三角形」等相似圖形，面積依然滿足 $A + B = C$！

• 雙向計算 SOP：
1. 求斜邊（最長邊）： 用加法開方 $\implies c = \sqrt{a^2 + b^2}$
2. 求股長（直角邊）： 用減法開方 $\implies b = \sqrt{c^2 - a^2}$（大平方減小平方）

• ⚠️ 雙解防呆警示： 若題目只說「三角形兩邊長為 3 與 4」，沒指明斜邊，則 4 可能是股（斜邊為 5），也可能是斜邊（另一股為 $\sqrt{4^2-3^2}=\sqrt{7}$），答案有兩個！

🧭 一、 核心概念與技能分析

• 特殊直角三角形邊長比：
- 45°-45°-90°（等腰直角）： 邊長比 $1 : 1 : \sqrt{2}$，正方形對角線 $d = s\sqrt{2}$。
- 30°-60°-90°： 邊長比 $1 : \sqrt{3} : 2$。
⚠️ 致命陷阱：斜邊是 2（最短邊的 2 倍），不是 $\sqrt{3}$！因為 $2 = \sqrt{4} > \sqrt{3}$！
- 正三角形公式： 邊長 $s$ 時，高 $h = \frac{\sqrt{3}}{2}s$、面積 $A = \frac{\sqrt{3}}{4}s^2$。

階段 3 ‧ 逆向思維與幾何代數化

逆定理形狀判定與坐標系距離：決策樹判別與平面距離幾何化

三邊長滿足平方和就是直角三角形！前置檢查 $a+b>c$ 防呆；在直角坐標系上以水平與垂直跨度駕馭畢氏定理！

🧭 一、 核心概念與技能分析

• 逆定理形狀判別 SOP：
步驟 0（前置防呆）： 必須先確認 $a + b > c$（兩短邊之和大於最長邊）！例如 2, 3, 5 連三角形都不是！
步驟 1（角度分類）： 令 $c$ 為最長邊：
- $a^2 + b^2 > c^2 \implies$ 銳角三角形
- $a^2 + b^2 = c^2 \implies$ 直角三角形（以 $c$ 為斜邊）
- $a^2 + b^2 < c^2 \implies$ 鈍角三角形

• 直角坐標系兩點距離公式（G-8-1）：
設平面兩點 $A(x_1, y_1), B(x_2, y_2)$： $$d = \overline{AB} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$ 中點坐標：$M = \left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$

🧭 一、 核心概念與技能分析

• 梯子靠牆下滑連鎖題 SOP：
1. 斜邊固定： 梯長 $L$ 永遠固定不變！
2. 前後兩次畢氏定理：原高 $h_1 = \sqrt{L^2 - d_1^2}$，下滑後新底 $d_2 = \sqrt{L^2 - h_2^2}$。
3. 外移量 $\Delta d = d_2 - d_1$（絕非等於下滑量 $\Delta h$）！

• 《九章算術》折竹著地建模：
整根竹高 $H$，折斷點離地 $x$，折倒斜邊為 $(H - x)$，滿足： $$x^2 + d^2 = (H - x)^2$$ • 立體空間對角線與展開圖：
- 長方體空間內部對角線：$D = \sqrt{a^2 + b^2 + c^2}$（兩次畢氏定理疊加）。
- 表面爬行最短路徑：立體問題平面化，畫出側面展開圖算斜邊！
