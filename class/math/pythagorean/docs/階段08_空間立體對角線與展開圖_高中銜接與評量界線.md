## 🏛️ 一、 長方體空間內部對角線推導

設長方體的長、寬、高分別為 $a, b, c$，求空間最長對角線 $AC'$：

```text
       D'-------------C'
      /|             /|
     / |            / |  c (高)
    A'-------------B' |
    |  D-----------|--C
    | /            | /   b (寬)
    |/             |/
    A--------------B
          a (長)
```

### 兩次畢氏定理疊加推導歷程：
1. **第一次畢氏定理（底面平面）**：
   在長方形底面 $ABCD$ 中，連接底面對角線 $AC$：
   底面直角三角形 $\triangle ABC$ 中，兩股為 $a$ 與 $b$：
   $$AC^2 = a^2 + b^2 \implies AC = \sqrt{a^2 + b^2}$$
2. **第二次畢氏定理（立體剖面）**：
   觀察直角三角形 $\triangle ACC'$：
   - 股長 1（底面對角線）：$AC = \sqrt{a^2 + b^2}$
   - 股長 2（垂直高）：$CC' = c$
   - 斜邊為空間對角線 $AC'$：
   $$AC'^2 = AC^2 + CC'^2 = (a^2 + b^2) + c^2 = a^2 + b^2 + c^2$$
3. **開平方求值**：
   $$\mathbf{AC' = \sqrt{a^2 + b^2 + c^2}}$$

> ⚡ **特例：正方體內部對角線**
> 若邊長皆為 $a$（正方體）：
> $$d = \sqrt{a^2 + a^2 + a^2} = \sqrt{3a^2} = \sqrt{3}a$$
> （段考極高頻率考正方體內部對角線長為邊長的 $\sqrt{3}$ 倍！）

## 🐜 二、 立體表面最短路徑（螞蟻爬行問題）

> **典型情境**：在長 5 公分、寬 4 公分、高 3 公分的長方體木盒上，一隻螞蟻想從頂點 $A$ 沿著外表面爬到對角頂點 $C'$，求螞蟻爬行的最短距離？

### 解題心智模型：展開為平面！
立體表面上的曲線或折線，在展開成平面後都會變成直線。
因為長方體有不同面，展開的方式有三種可能：
1. **路徑一（經過前面與右面）**：
   展開後矩形長度為 $(5 + 4) = 9$，高度為 $3$：
   $$d_1 = \sqrt{(5+4)^2 + 3^2} = \sqrt{9^2 + 3^2} = \sqrt{81 + 9} = \sqrt{90} = 3\sqrt{10} \approx 9.49$$
2. **路徑二（經過前面與上面）**：
   展開後矩形長度為 $5$，高度為 $(4 + 3) = 7$：
   $$d_2 = \sqrt{5^2 + (4+3)^2} = \sqrt{25 + 49} = \sqrt{74} \approx 8.60$$
3. **路徑三（經過左面與上面）**：
   展開後矩形長度為 $(5 + 3) = 8$，高度為 $4$：
   $$d_3 = \sqrt{(5+3)^2 + 4^2} = \sqrt{64 + 16} = \sqrt{80} = 4\sqrt{5} \approx 8.94$$

> 🏆 **比較大小結論**：最短路徑為 $\sqrt{74}$ 公分（將兩較小邊 4 與 3 合併在同一直線上運算）！

## ✏️ 隨堂實戰練習

### 練習 1
邊長為 6 公分的正方體，其空間內部對角線長度為多少公分？
- **解答與思路**：
  直接代入正方體對角線公式：$d = \sqrt{3} \times a = 6\sqrt{3}$ 公分。

### 練習 2
長方體長 12 公分、寬 4 公分、高 3 公分，求其內部空間對角線長？
- **解答與思路**：
  $d = \sqrt{12^2 + 4^2 + 3^2} = \sqrt{144 + 16 + 9} = \sqrt{169} = 13$ 公分。
  （可觀察先由 $4$ 與 $3$ 得底面對角線 5，再由 $12$ 與 $5$ 得斜邊 13，連環勾股數！）
