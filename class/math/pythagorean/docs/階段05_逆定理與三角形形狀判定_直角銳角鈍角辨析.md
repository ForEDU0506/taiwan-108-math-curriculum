# 階段 5：逆定理與三角形形狀判定（直角、銳角、鈍角辨析）

## 🎯 學習目標
1. 理解畢氏定理的「逆定理（Converse Theorem）」：若三邊長滿足 $a^2 + b^2 = c^2$（$c$ 為最大邊），則此三角形必為直角三角形。
2. 掌握三角形形狀的代數判定法則：
   - $a^2 + b^2 = c^2 \iff$ 直角三角形
   - $a^2 + b^2 > c^2 \iff$ 銳角三角形
   - $a^2 + b^2 < c^2 \iff$ 鈍角三角形
3. 建立前置檢驗抗體：在進行平方和判定前，**必須先檢驗是否滿足「兩短邊之和大於第三邊（$a + b > c$）」**，確認能形成三角形。

---

## 💡 概念引導：如何只看三邊長，就能知道三角形的形狀？

在一個三角形中，設三邊長分別為 $a, b, c$，且 **$c$ 為最長邊**：

### 1. 幾何動態直觀（角的張開與閉合）
想像用長度為 $a$ 和 $b$ 的兩根木棒，夾角從 $0^\circ$ 慢慢張開到 $180^\circ$：
- **當夾角恰為 $90^\circ$（直角）時**：
  對面的第三邊木棒長度平方剛好等於兩邊平方和：$$c^2 = a^2 + b^2$$
- **當夾角小於 $90^\circ$（縮小為銳角）時**：
  對面的第三邊長度縮短了，使得：$$c^2 < a^2 + b^2 \iff a^2 + b^2 > c^2$$
- **當夾角大於 $90^\circ$（張開為鈍角）時**：
  對面的第三邊長度被撐長了，使得：$$c^2 > a^2 + b^2 \iff a^2 + b^2 < c^2$$

## ⚡ 三角形形狀判定 SOP（三步驟絕對無死角）

```text
【步驟一：排列大小順序】
  將三邊長由小到大排列：a ≤ b ≤ c（確認 c 為最長邊）。
         │
         ▼
【步驟二：前置檢驗（三角形能否形成）】
  檢驗是否滿足「兩小邊之和大於最大邊」：a + b > c。
  • 若 a + b ≤ c ➔ 根本無法構成三角形！（直接結案，不需算平方）
  • 若 a + b > c ➔ 確定是三角形，進入步驟三。
         │
         ▼
【步驟三：平方和比大小】
  計算兩小邊平方和 a^2 + b^2，與最大邊平方 c^2 進行比較：
  • a^2 + b^2 = c^2 ➔ 直角三角形（最大角為 90°）
  • a^2 + b^2 > c^2 ➔ 銳角三角形（三個角皆小於 90°）
  • a^2 + b^2 < c^2 ➔ 鈍角三角形（最大角大於 90°）
```

## ⚠️ 常見易錯陷阱

> [!CAUTION]
> **陷阱 1：漏掉前置檢驗，誤把「不是三角形」判定為鈍角！**  
> 題目：三邊長分別為 $1, 2, 3$，此三角形為何種形狀？  
> ❌ 盲目計算：$1^2 + 2^2 = 1 + 4 = 5 < 3^2 = 9$ ➔ 判定為「鈍角三角形」。  
> ✅ 正確思維：先看兩短邊之和 $1 + 2 = 3$ **沒有大於 3**！這三條線段連起來是一條直線，**根本無法構成三角形**！

> [!CAUTION]
> **陷阱 2：忘記確認 $c$ 必須是最長邊！**  
> 題目：三邊長為 $13, 12, 5$。  
> 若未排序誤拿 $13^2 + 12^2$ 和 $5^2$ 比較，會得出錯誤結論。一定要找最大邊 $13$，檢驗 $5^2 + 12^2 = 25 + 144 = 169 = 13^2$ 才是直角三角形。

## ✏️ 隨堂實戰練習

### 練習 1
下列各組數值為三角形的三邊長，請判斷各屬於「銳角、直角、鈍角」三角形或「無法形成三角形」？
1. $6, 8, 10$
2. $4, 5, 6$
3. $5, 7, 13$
4. $5, 6, 8$

- **解答與思路**：
  1. $6+8=14>10$（形成三角形）。$6^2+8^2 = 36+64 = 100 = 10^2$ ➔ **直角三角形**。
  2. $4+5=9>6$（形成三角形）。$4^2+5^2 = 16+25 = 41 > 6^2 = 36$ ➔ **銳角三角形**。
  3. $5+7=12 < 13$ ➔ 兩短邊之和小於第三邊，**無法形成三角形**。
  4. $5+6=11>8$（形成三角形）。$5^2+6^2 = 25+36 = 61 < 8^2 = 64$ ➔ **鈍角三角形**。
