# 階段 7：乘法公式應用與雙項式分母有理化

## 一、 核心概念引導：把八上乘法公式套用到根式中！

在八年級上學期第 1 章中，我們熟練掌握了三大乘法公式：
1. **分配律**：$m(a + b) = ma + mb$
2. **平方差公式**：$(a + b)(a - b) = a^2 - b^2$
3. **和平方 / 差平方公式**：$(a \pm b)^2 = a^2 \pm 2ab + b^2$

當我們把數字換成根式時，神奇的性質出現了：**根號平方會直接變成整數！**

---

### 1. 根式的分配律展開
$$\sqrt{a}(\sqrt{b} + \sqrt{c}) = \sqrt{ab} + \sqrt{ac}$$
$$(\sqrt{a} + \sqrt{b})(\sqrt{c} + \sqrt{d}) = \sqrt{ac} + \sqrt{ad} + \sqrt{bc} + \sqrt{bd}$$

---

### 2. 平方差公式在根式中的應用（根號的剋星）
$$(\sqrt{a} + \sqrt{b})(\sqrt{a} - \sqrt{b}) = (\sqrt{a})^2 - (\sqrt{b})^2 = a - b$$

#### 💡 為什麼這個公式極其重要？
兩個含有根式的括號相乘，相乘後的結果居然**完全沒有根號，直接變成有理整數 $a - b$！**  
這就是我們解決雙項式分母有理化的終極法寶！

---

### 3. 和平方與差平方公式（切記中間項！）
$$(\sqrt{a} + \sqrt{b})^2 = (\sqrt{a})^2 + 2\sqrt{a}\sqrt{b} + (\sqrt{b})^2 = a + 2\sqrt{ab} + b = (a + b) + 2\sqrt{ab}$$
$$(\sqrt{a} - \sqrt{b})^2 = (a + b) - 2\sqrt{ab}$$

---

### 4. 雙項式分母有理化（🌟 挑戰延伸：利用平方差公式消除分母根號）

> 📌 **課綱界線提醒**：  
> 108 課綱國中基本標準為「單項分母有理化」（如 $\frac{6}{\sqrt{3}} = 2\sqrt{3}$）。  
> 雙項分母有理化屬於「高中銜接與延伸挑戰題」（高中數學才會正式引入「共軛根式」這個專有名詞）。  
> 在國中階段，我們不必死背高中術語，只要靈活運用第一章已學過的**「平方差好朋友：$(a+b)(a-b) = a^2 - b^2$」**，就能輕鬆消掉分母根號！

如果分母不是單項（如 $\frac{1}{\sqrt{2} - 1}$），我們不能只乘 $\sqrt{2}$，因為會變成 $\frac{\sqrt{2}}{2 - \sqrt{2}}$，分母依然有根號！

> **必殺技：利用平方差公式擴分！**  
> - 若分母是 $\sqrt{a} - b$，分子分母同乘其平方差搭檔 **$(\sqrt{a} + b)$**。  
> - 若分母是 $\sqrt{a} + b$，分子分母同乘其平方差搭檔 **$(\sqrt{a} - b)$**。

#### 示範：
$$\frac{1}{\sqrt{2} - 1} = \frac{1 \times (\sqrt{2} + 1)}{(\sqrt{2} - 1)(\sqrt{2} + 1)} = \frac{\sqrt{2} + 1}{(\sqrt{2})^2 - 1^2} = \frac{\sqrt{2} + 1}{2 - 1} = \sqrt{2} + 1$$

## 二、 ⚠️ 致命迷思防範（兩大送分題變扣分題）

> 🚨 **陷阱 1：和平方公式漏掉中間項 $2\sqrt{ab}$**  
> 誤以為 $(\sqrt{3} + \sqrt{2})^2 = 3 + 2 = 5$。（完全錯誤！）  
> 💡 **正確算式**：  
> $(\sqrt{3} + \sqrt{2})^2 = (\sqrt{3})^2 + 2(\sqrt{3})(\sqrt{2}) + (\sqrt{2})^2 = 3 + 2\sqrt{6} + 2 = \mathbf{5 + 2\sqrt{6}}$！
> 
> 🚨 **陷阱 2：平方差公式減法順序顛倒**  
> 計算 $(1 - \sqrt{3})(1 + \sqrt{3})$ 誤寫成 $3 - 1 = 2$。  
> 💡 **正確算式**：  
> $1^2 - (\sqrt{3})^2 = 1 - 3 = \mathbf{-2}$！前面的平方減後面的平方，順序不可任意對調！

## 三、 範例引導教學

### 📘 【範例 1：分配律展開】
**題目**：展開並化簡 $(\sqrt{3} + 2)(\sqrt{3} - 5)$。  
**思考階梯**：
- 第一項乘第一項：$\sqrt{3} \times \sqrt{3} = 3$
- 外項相乘：$\sqrt{3} \times (-5) = -5\sqrt{3}$
- 內項相乘：$2 \times \sqrt{3} = 2\sqrt{3}$
- 末項乘末項：$2 \times (-5) = -10$
- 合併整數與根式：$(3 - 10) + (-5 + 2)\sqrt{3} = -7 - 3\sqrt{3}$。  
**答**：$-7 - 3\sqrt{3}$。

---

### 📘 【範例 2：平方差與和平方公式】
**題目**：計算下列各式：  
(1) $(\sqrt{7} + \sqrt{3})(\sqrt{7} - \sqrt{3})$  
(2) $(\sqrt{5} - \sqrt{2})^2$  
**思考階梯**：
- (1) 套用平方差公式：$(\sqrt{7})^2 - (\sqrt{3})^2 = 7 - 3 = 4$。
- (2) 套用差平方公式：$(\sqrt{5})^2 - 2\sqrt{5}\sqrt{2} + (\sqrt{2})^2 = 5 - 2\sqrt{10} + 2 = 7 - 2\sqrt{10}$。  
**答**：(1) $4$；(2) $7 - 2\sqrt{10}$。

---

### 📘 【範例 3：雙項式分母有理化】
**題目**：將下列各式分母有理化：  
(1) $\frac{1}{\sqrt{5} + \sqrt{2}}$  
(2) $\frac{\sqrt{3} - 1}{\sqrt{3} + 1}$  
**思考階梯**：
- (1) 利用平方差公式，分子分母同乘 $(\sqrt{5} - \sqrt{2})$：  
  $\frac{1 \times (\sqrt{5} - \sqrt{2})}{(\sqrt{5} + \sqrt{2})(\sqrt{5} - \sqrt{2})} = \frac{\sqrt{5} - \sqrt{2}}{5 - 2} = \frac{\sqrt{5} - \sqrt{2}}{3}$。
- (2) 利用平方差公式，分子分母同乘 $(\sqrt{3} - 1)$：  
  分母 $= (\sqrt{3})^2 - 1^2 = 3 - 1 = 2$  
  分子 $= (\sqrt{3} - 1)^2 = 3 - 2\sqrt{3} + 1 = 4 - 2\sqrt{3}$  
  全式 $= \frac{4 - 2\sqrt{3}}{2} = 2 - \sqrt{3}$（分子分母同時除以 2 約分）。  
**答**：(1) $\frac{\sqrt{5} - \sqrt{2}}{3}$；(2) $2 - \sqrt{3}$。

## 四、 實戰梯度演練

### 基礎題
1. 計算 $(\sqrt{6} + 1)(\sqrt{6} - 1)$ 之值。
2. 計算 $(\sqrt{7} + \sqrt{2})^2$ 之值。
3. 計算 $(2\sqrt{3} - 3)^2$ 之值。

### 進階題
4. 將下列各式分母有理化：  
   (1) $\frac{2}{\sqrt{7} - \sqrt{5}}$  
   (2) $\frac{1}{2 + \sqrt{3}}$  
5. 計算 $\frac{1}{\sqrt{2}+1} + \frac{1}{\sqrt{3}+\sqrt{2}} + \frac{1}{2+\sqrt{3}}$ 之值。

---

### 📝 參考解答與解析
1. **答**：$5$。（解析：$(\sqrt{6})^2 - 1^2 = 6 - 1 = 5$）
2. **答**：$9 + 2\sqrt{14}$。（解析：$7 + 2\sqrt{14} + 2 = 9 + 2\sqrt{14}$）
3. **答**：$21 - 12\sqrt{3}$。（解析：$(2\sqrt{3})^2 - 2(2\sqrt{3})(3) + 3^2 = 12 - 12\sqrt{3} + 9 = 21 - 12\sqrt{3}$）
4. **答**：  
   (1) $\frac{2(\sqrt{7}+\sqrt{5})}{7-5} = \frac{2(\sqrt{7}+\sqrt{5})}{2} = \sqrt{7} + \sqrt{5}$。  
   (2) $\frac{2-\sqrt{3}}{2^2 - (\sqrt{3})^2} = \frac{2-\sqrt{3}}{4-3} = 2 - \sqrt{3}$。
5. **答**：$1$。  
   （解析：經典對消題！  
   第 1 項 $= \sqrt{2} - 1$；  
   第 2 項 $= \sqrt{3} - \sqrt{2}$；  
   第 3 項 $= \frac{2-\sqrt{3}}{4-3} = 2 - \sqrt{3}$。  
   相加：$(\sqrt{2}-1) + (\sqrt{3}-\sqrt{2}) + (2-\sqrt{3}) = -1 + 2 = 1$！）
