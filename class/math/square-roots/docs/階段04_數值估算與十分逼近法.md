# 階段 4：數值估算與十分逼近法

## 一、 核心概念引導：如何知道 $\sqrt{a}$ 大約是多少？

在日常生活中，如果看到 $\sqrt{10}$，它大約是幾點幾？買多長的木板才夠？  
我們不可能隨時都有計算機，但我們可以透過**「完全平方數夾擠法」**快速估算出它的整數範圍！

---

### 1. 完全平方數夾擠法（求整數部分）

> **夾擠定理思維**：  
> 若 $m^2 < a < (m+1)^2$，其中 $m$ 為正整數，  
> 則開根號後：**$m < \sqrt{a} < m+1$**。  
> 此時，$\sqrt{a}$ 的**整數部分就是 $m$**。

#### 示範：求 $\sqrt{30}$ 的整數部分
1. 列出 30 附近的完全平方數：
   - $4^2 = 16$
   - $5^2 = 25$
   - $6^2 = 36$
2. 我們發現：$25 < 30 < 36$（即 $5^2 < 30 < 6^2$）。
3. 同時開根號：$\sqrt{25} < \sqrt{30} < \sqrt{36}$。
4. 得到：$5 < \sqrt{30} < 6$。
5. 結論：$\sqrt{30}$ 介於 5 與 6 之間，大約是 $5.\dots$，其整數部分為 **5**。

---

### 2. 十分逼近法（逐步逼近小數位數）

如果想要更精確知道小數點後第一位是多少，我們可以利用**十分逼近法**：
以 $\sqrt{2}$ 為例：
- 已知 $1 < \sqrt{2} < 2$（因為 $1^2 = 1 < 2 < 4 = 2^2$）。
- **測試十分位（小數點後第一位）**：
  - $1.1^2 = 1.21$
  - $1.2^2 = 1.44$
  - $1.3^2 = 1.69$
  - $1.4^2 = 1.96 < 2$
  - $1.5^2 = 2.25 > 2$
  - 發現：$1.4^2 < 2 < 1.5^2 \implies \mathbf{1.4 < \sqrt{2} < 1.5}$。
- **測試百分位（小數點後第二位）**：
  - $1.41^2 = 1.9881 < 2$
  - $1.42^2 = 2.0164 > 2$
  - 發現：$1.41^2 < 2 < 1.42^2 \implies \mathbf{1.41 < \sqrt{2} < 1.42}$。
- 依此類推，可以逼近到任意精確度！

### 3. 計算機輔助建立數感
在現代課綱中，計算機是探索數學工具的重要夥伴：
- 按下數字鍵 `2`，再按下 `√` 鍵，螢幕顯示：`1.41421356...`
- 按下數字鍵 `3`，再按下 `√` 鍵，螢幕顯示：`1.7320508...`
- 按下數字鍵 `5`，再按下 `√` 鍵，螢幕顯示：`2.2360679...`
> **數感記憶小常識**（常用近似值）：  
> $\sqrt{2} \approx 1.414$（意思意思）  
> $\sqrt{3} \approx 1.732$（一起想念）  
> $\sqrt{5} \approx 2.236$（惡鄰三六）

## 二、 範例引導教學

### 📘 【範例 1：求連續整數範圍】
**題目**：設 $a$ 為正整數，若 $a < \sqrt{220} < a + 1$，求 $a$ 之值。  
**思考階梯**：
- 第一步：回想完全平方數列表。
  - $14^2 = 196$
  - $15^2 = 225$
- 第二步：比對 220 落在誰與誰之間？  
  $196 < 220 < 225 \implies 14^2 < 220 < 15^2$。
- 第三步：開根號得到 $14 < \sqrt{220} < 15$。
- 第四步：對照式子 $a < \sqrt{220} < a + 1$，得 $a = 14$。  
**答**：$a = 14$。

---

### 📘 【範例 2：整數部分與小數部分】
**題目**：已知 $\sqrt{10}$ 的整數部分為 $x$，小數部分為 $y$，求 $x$ 與 $y$ 之值。  
**思考階梯**：
- 第一步：夾擠求整數部分。  
  $3^2 = 9 < 10 < 16 = 4^2 \implies 3 < \sqrt{10} < 4$。  
  所以整數部分 $x = 3$。
- 第二步：小數部分怎麼表示？  
  任何數 $=$ 整數部分 $+$ 小數部分 $\implies$ **小數部分 $=$ 原數 $-$ 整數部分**！
- 第三步：因此小數部分 $y = \sqrt{10} - 3$。  
**答**：$x = 3$，$y = \sqrt{10} - 3$。

---

## 三、 ⚠️ 常見陷阱與迷思概念防範

> ❌ **陷阱**：誤以為 $y = 0.16$（直接將小數點剪下）。  
> 💡 **診斷**：$\sqrt{10}$ 是無理數，小數部分無窮無盡，無法寫成有限小數，最精確的表示法就是「原數減去整數」，即 $\sqrt{10} - 3$！

## 四、 實戰梯度演練

### 基礎題
1. 介於哪兩個連續整數之間？  
   (1) $\sqrt{53}$  
   (2) $\sqrt{110}$  
2. 求 $\sqrt{85}$ 的整數部分。

### 進階題
3. 若 $k < \sqrt{350} < k + 1$，$k$ 為整數，求 $k$。
4. 已知 $\sqrt{7}$ 的整數部分為 $a$，小數部分為 $b$：  
   (1) 求 $a$ 與 $b$ 的值。  
   (2) 計算 $a + \frac{1}{b+2}$ 的值。

---

### 📝 參考解答與解析
1. **答**：  
   (1) 介於 $7$ 與 $8$ 之間。（解析：$7^2 = 49 < 53 < 64 = 8^2$）  
   (2) 介於 $10$ 與 $11$ 之間。（解析：$10^2 = 100 < 110 < 121 = 11^2$）
2. **答**：$9$。（解析：$9^2 = 81 < 85 < 100 = 10^2 \implies 9 < \sqrt{85} < 10$）
3. **答**：$k = 18$。（解析：$18^2 = 324$，$19^2 = 361$。$324 < 350 < 361 \implies 18 < \sqrt{350} < 19$）
4. **答**：  
   (1) $a = 2$，$b = \sqrt{7} - 2$。（解析：$2^2 = 4 < 7 < 9 = 3^2 \implies 2 < \sqrt{7} < 3$）  
   (2) 原式 $= 2 + \frac{1}{(\sqrt{7}-2)+2} = 2 + \frac{1}{\sqrt{7}} = 2 + \frac{\sqrt{7}}{7}$。
