# 臺灣 108 數學課綱學習活動設計網站

> 數學來自生活，學習回到生活。

這是網站第一階段的靜態架構雛型，使用 GitHub Pages 可直接發布。網站以內容為主、索引為輔，連結：

- 官方課綱與學習內容（後續建立）
- 一般教學設計
- 學術與現場實務（獨立於一般教案，不以熱門度混排）
- 生活情境與數學素養
- 學生數學日記（目前只預留位置，尚未開放）

## 目前檔案

- `index.html`：首頁與內容分流架構，整合編輯精選與主題索引
- `list.html`：教材列表頁，支援年級、主題與類型的動態篩選
- `detail.html`：教材詳情範例頁（課綱正負數主題）
- `lesson-1011102.html`：經典教案實錄（草山遊學—藍染中的幾何對稱與圖形推理，日新三資 1011102）
- `lesson-1011115.html`：思維教案實錄（語意理解與算式填充題—加減逆運算與情境擬題，日新三資 1011115 / 1011224）
- `lesson-dadaocheng.html`：校本特色課程（河映史蹟藝趣稻埕—建築幾何與跨領域生活數學素養）
- `styles.css`：視覺樣式、可收合索引、響應式版面
- `app.js`：搜尋、年級與主題篩選、索引收合

## 學生數學日記的預留原則

學生數學日記先保留獨立區域，不在第一階段混入教師投稿，也不預設形式。未來可依實際討論容納短篇文字、圖像或其他小型學習紀錄；若作為研究資料，必須另行設計同意、匿名、審核、撤下與資料保存規則。

## 本地預覽

直接用瀏覽器開啟 `index.html` 即可預覽。若要發布到 GitHub Pages，可在 Repository 的 **Settings → Pages** 選擇 `main` 分支與根目錄。
