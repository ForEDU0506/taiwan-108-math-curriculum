日新國小資優班思維教材實錄 1011115 / 1011224

語意理解與算式填充題：加減逆運算與情境擬題

不只是死背「求加數用減法」，而是建立「推想情境 ➔ 圈關鍵字 ➔ 列未知數式」的三步思考鷹架；更讓孩子反向為算式創編生活故事，達成真正的代數前置思維。

三年級 R 關係與代數思維 R-3-2 加減互逆 R-3-1 算式與符號括號 情境擬題與數學建模

🎯 1. 教材設計背景：破除「算術盲猜運算符號」的痛點

小學中年級學生在面對應用問題時，常見的最大瓶頸是：「看見題目有兩個數字，就隨便抓起來加一加或減一減」，缺乏對題幹語意關係的理解。

為了解決這個現場核心痛點，本教材設計了一套結構化的三步驟思維鷹架，並引進「計算題情境化練習」（逆向擬題），讓學生從「解題者」提升為「情境編撰者與問題建立者」。

🪜 2. 依題意列式的「三步思維鷹架」

1 由題目語意推想生活情境（語言層次）

先不要急著寫數字！先用自己的話說出整體情境架構：
「原來有的數量，加上後來游來的數量，會等於全部的數量。」

2 圈出決定運算符號的關鍵字，列出關係式（結構層次）

圈出關鍵字詞（例如：「再...就會有...」）。將文字關係轉譯為運算關係式：
原來的 ＋ 後來的 ＝ 全部的

3 將所求項目以 ( ) 表示，列出算式填充題（符號代數層次）

將題目問的未知數填入括號，列出精確算式填充題：
403 ＋ (   ) ＝ 600

🔄 3. 求解要點：加減互逆的算理理解

在國小三年級，括號 ( ) 就是國中代數方程式中未知數 x 的前身。學生需要掌握「逆運算」原理：

【範例一：求加數】櫻花鉤吻鮭的生活題

題目：溪中有 403 條櫻花鉤吻鮭，再游來幾條，就會有 600 條櫻花鉤吻鮭？

算式填充題：403 ＋ (   ) ＝ 600

計算要點：當要求出的答案是「加數」，而不是「和」時，要以「和」去減掉「被加數」。

計算過程（拆解心算巧思）：
600 － 403 ＝ 600 － 400 － 3 ＝ 200 － 3 ＝ 197
答：197 條

【範例二：求被加數】玲玲存錢的撲滿題

題目：玲玲的撲滿裡原有一些錢，再存 27 元，撲滿裡就有 420 元，玲玲原來有多少元？

關係式：原來的錢 ＋ 存進去的錢 ＝ 現在有的錢

算式填充題：(   ) ＋ 27 ＝ 420

計算過程：420 － 27 ＝ 393 （答：393 元）

【範例三：線段圖視覺表徵】烏龜與兔子賽跑

題目：烏龜跑了 365 公尺，還要跑多少公尺，才會到達兔子休息的地方（526 公尺處）？

算式填充題：365 ＋ (   ) ＝ 526 ➔ 526 － 365 ＝ 161（答：161 公尺）

✍️ 4. 創新教學亮點：計算題情境化練習（情境擬題）

傳統練習給情境求答案，本教材反向要求：「給出抽象算式，由學生自主創作生活情境題目」！

  • 題目一：289 ＋ (   ) ＝ 958
    引導詞：「再…… 就會有……」
    示範創作：溪中有 289 條櫻花鉤吻鮭，再游來幾條，就會有 958 條櫻花鉤吻鮭？
  • 題目二：(   ) ＋ 239 ＝ 621
    引導詞：「原本有…… 又增加了…… 現在共有……」
    讓學生練習編寫「被加數未知」的存錢、收集卡片或排隊情境。
  • 題目三：399 ＋ (   ) ＝ 2425
    進階大數情境，引導學生融入生活經驗（購物預算、跑步里程、書本頁數等）。

💡 5. 教學現場成效與省思

透過這樣的訓練，孩子在面對文字題時不再焦慮，因為他們腦中已經建立起清晰的解題地圖：

  1. 遇到問題先找情境主軸，判斷是「增加（加法）」還是「減少（減法）」。
  2. 把不知道的東西用 ( ) 穩穩地框在算式裡，不要急著心算跳步。
  3. 最後利用「和減被加數」或「和減加數」的互逆關係從容計算。
