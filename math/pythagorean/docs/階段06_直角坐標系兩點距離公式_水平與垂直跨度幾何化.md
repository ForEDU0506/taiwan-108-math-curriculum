# 階段 6：直角坐標系兩點距離公式（水平與垂直跨度幾何化）

## 🎯 學習目標
1. 能在平面直角坐標系中，將任意兩點 $A(x_1, y_1)$ 與 $B(x_2, y_2)$ 之間的距離轉化為直角三角形的斜邊長度。
2. 掌握坐標兩點距離公式：$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
3. 熟練原點 $O(0, 0)$ 到任意點 $P(x, y)$ 的距離公式：$OP = \sqrt{x^2 + y^2}$，並能應用於幾何圖形周長與面積運算。

---

## 💡 概念引導：坐標距離公式就是畢氏定理的代數化！

在平面直角坐標系中，要求兩點 $A(x_1, y_1)$ 與 $B(x_2, y_2)$ 的直線距離 $d$：

### 1. 幾何構造（畫出直角三角形）
1. 過點 $A$ 作水平線，過點 $B$ 作鉛直線，兩線交於點 $C(x_2, y_1)$。
2. 因為坐標軸的 $x$ 軸與 $y$ 軸互相垂直，所以 $\angle ACB = 90^\circ$ 是一個標準的直角三角形！
3. 其中：
   - 水平股長（底邊）：$AC = |x_2 - x_1|$
   - 垂直股長（高）：$BC = |y_2 - y_1|$
   - 斜邊長即為我們要算的距離 $AB$。

### 2. 套用畢氏定理推導
由畢氏定理：斜邊長 = 兩股平方和開根號：
$$AB^2 = AC^2 + BC^2$$
$$d^2 = (|x_2 - x_1|)^2 + (|y_2 - y_1|)^2 = (x_2 - x_1)^2 + (y_2 - y_1)^2$$
因為距離必定為非負數，開平方取正值：
$$\mathbf{d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}}$$

> ⚡ **秒殺記憶口訣**：
> - **「$x$ 坐標相減平方 ＋ $y$ 坐標相減平方，加起來開根號！」**
> - 因為有平方，所以誰減誰都沒關係：$(x_2 - x_1)^2 = (x_1 - x_2)^2$！

## 🔍 範例導引：解題階梯

### 範例 1：求兩點距離
求坐標平面上兩點 $A(2, -1)$ 與 $B(5, 3)$ 之間的距離？
1. **計算水平差 $\Delta x$**：$5 - 2 = 3$ ➔ $3^2 = 9$。
2. **計算垂直差 $\Delta y$**：$3 - (-1) = 3 + 1 = 4$ ➔ $4^2 = 16$。
3. **加總開方**：
   $$AB = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$
   （敏銳度高者可直接看出 $3 : 4 : 5$ 直角三角形，心算秒殺！）

### 範例 2：原點距離特例
求原點 $O(0, 0)$ 到點 $P(-6, 8)$ 的距離？
$$OP = \sqrt{(-6)^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10$$
（同樣是 $6-8-10$ 勾股數組，邊長比 $3:4:5$ 的 2 倍縮放！）

## ⚠️ 常見易錯陷阱

> [!CAUTION]
> **陷阱 1：負數相減忘記變號！**  
> 計算 $3 - (-1)$ 時，常粗心算成 $3 - 1 = 2$。  
> 記住：減負數等於加正數！距離是指數線上的跨度，從 $-1$ 走到 $3$ 一共走了 4 格！

> [!CAUTION]
> **陷阱 2：忘記開根號！**  
> 算出 $(x_2 - x_1)^2 + (y_2 - y_1)^2 = 25$ 後，就直接把 25 當作答案。請務必記得公式最外層有根號！

## ✏️ 隨堂實戰練習

### 練習 1
平面上有兩點 $P(-3, 4)$ 與 $Q(1, 1)$，求線段 $PQ$ 的長度？
- **解答與思路**：
  $\Delta x = 1 - (-3) = 4$
  $\Delta y = 1 - 4 = -3$
  $PQ = \sqrt{4^2 + (-3)^2} = \sqrt{16 + 9} = \sqrt{25} = 5$。

### 練習 2
若點 $A(k, 2)$ 到原點 $O(0, 0)$ 的距離為 $\sqrt{13}$，求 $k$ 的值？
- **解答與思路**：
  $OA = \sqrt{k^2 + 2^2} = \sqrt{k^2 + 4}$。
  已知 $\sqrt{k^2 + 4} = \sqrt{13}$，兩邊平方：
  $k^2 + 4 = 13 \implies k^2 = 9 \implies k = \pm 3$。
  （注意：坐標可以是正也可以是負，故答案有兩個：$3$ 或 $-3$！）
