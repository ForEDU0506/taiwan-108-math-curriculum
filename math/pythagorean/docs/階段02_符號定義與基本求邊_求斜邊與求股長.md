# 階段 2：符號定義與基本求邊（求斜邊與求股長）

## 🎯 學習目標
1. 掌握標準畢氏定理公式符號：$a^2 + b^2 = c^2$，其中 $c$ 為直角所對之最長邊（斜邊）。
2. 能熟練進行「求斜邊（用加法開方）」與「求股長（用大平方減小平方開方）」之分流運算。
3. 連結二次方根取正值特性：幾何長度必大於 0，開方結果一律取正。

---

## 💡 核心公式與運算分流 SOP

在直角三角形 $ABC$ 中，若 $\angle C = 90^\circ$，則：
- 直角邊（股）：$a$ 與 $b$
- 斜邊（對面最長邊）：$c$

$$\mathbf{a^2 + b^2 = c^2}$$

### 運算分流雙通道：

| 求解目標 | 所用算式 | 運算關鍵思路 | 範例（以兩邊 5、12 為例） |
| :--- | :--- | :--- | :--- |
| **已知兩股，求斜邊 $c$** | $$c = \sqrt{a^2 + b^2}$$ | **加法開方**（兩股平方相加） | $c = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13$ |
| **已知斜邊與一股，求另一股 $a$** | $$a = \sqrt{c^2 - b^2}$$ | **減法開方**（斜邊平方減股平方） | $a = \sqrt{13^2 - 12^2} = \sqrt{169 - 144} = \sqrt{25} = 5$ |

> ⚡ **秒殺記憶口訣**：
> - **求最長邊（斜邊） ➔ 平方相加再開根！**
> - **求直角邊（股長） ➔ 大平方減小平方再開根！**

---

## 🔍 範例導引：運算階梯示范

### 範例 1：求斜邊（整數值與非整數根式化簡）
已知直角三角形兩股長分別為 6 與 7，求斜邊長？
1. **確認直角邊**：$a = 6, b = 7$。
2. **列出斜邊公式**：$c = \sqrt{a^2 + b^2} = \sqrt{6^2 + 7^2}$。
3. **計算平方和**：$36 + 49 = 85$。
4. **化為最簡根式**：$85 = 5 \times 17$ 無平方因數，故斜邊為 $\sqrt{85}$。

### 範例 2：求股長（逆向移項運算）
已知直角三角形斜邊長為 10，其中一股長為 6，求另一股長？
1. **確認斜邊與已知股**：$c = 10, b = 6$。
2. **列出求股公式**：$a = \sqrt{c^2 - b^2} = \sqrt{10^2 - 6^2}$。
3. **計算平方差**：$100 - 36 = 64$。
4. **開方求值**：$\sqrt{64} = 8$。另一股長為 8。

---

## ⚠️ 常見易錯陷阱

> [!CAUTION]
> **陷阱 1：求股長時誤用加法！**  
> 許多學生習慣性地將題目出現的兩個數字平方相加：
> 錯誤：$a = \sqrt{10^2 + 6^2} = \sqrt{136}$（❌ 股長不可能大於斜邊 10！）  
> 正確：股長是直角邊，必定小於斜邊，一定要用「$10^2 - 6^2$」！

> [!CAUTION]
> **陷阱 2：直接把平方差開方！**  
> 錯誤：$\sqrt{10^2 - 6^2} = 10 - 6 = 4$（❌ 根號內減法不可分開開方！）  
> 正確：必須先算根號內的數值 $100 - 36 = 64$，再開方得 $\sqrt{64} = 8$。

## ✏️ 隨堂實戰練習

### 練習 1
直角三角形兩股長為 $\sqrt{5}$ 與 $\sqrt{11}$，求其斜邊長？
- **解答與思路**：
  $c = \sqrt{(\sqrt{5})^2 + (\sqrt{11})^2} = \sqrt{5 + 11} = \sqrt{16} = 4$。

### 練習 2
直角三角形斜邊長為 9，一股長為 3，求另一股長？
- **解答與思路**：
  $a = \sqrt{9^2 - 3^2} = \sqrt{81 - 9} = \sqrt{72}$。
  將 $\sqrt{72}$ 化為最簡根式：$\sqrt{36 \times 2} = 6\sqrt{2}$。
