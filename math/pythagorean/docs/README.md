## 💡 教學與自主學習建議
1. **先抓直角與斜邊**：看到圖形第一步，手指直角符號 $\llcorner$，其對面就是最長邊 $c$。
2. **公式分流防呆**：
   - 求斜邊 ➔ 用「加法」：$c = \sqrt{a^2 + b^2}$
   - 求股長 ➔ 用「減法」：$a = \sqrt{c^2 - b^2}$（大平方減小平方）
3. **善用整數勾股數比例約分**：遇大數字先約分，找出基本組（3-4-5 等）再放大，算得又快又準。
4. **結合二次方根化簡**：所有開根號結果一律化為最簡根式，完美鞏固前一章能力。
