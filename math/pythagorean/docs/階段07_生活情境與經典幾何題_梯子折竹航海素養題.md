## 🏛️ 三大經典情境數學模型精析

### 1. 梯子滑落問題（斜邊守恆定理）
> **情境**：一架長 $2.5$ 公尺的梯子靠在垂直牆上，梯腳離牆底 $0.7$ 公尺。若梯頂下滑了 $0.4$ 公尺，請問梯腳向外滑動了多少公尺？

**解題思考階梯**：
- **狀態一（滑落前）**：
  - 梯長 $c = 2.5$（斜邊）
  - 梯腳離牆底 $a_1 = 0.7$（底股）
  - 原本牆高 $b_1 = \sqrt{2.5^2 - 0.7^2} = \sqrt{6.25 - 0.49} = \sqrt{5.76} = 2.4$ 公尺。（可聯想 $7-24-25$ 勾股數除以 10！）
- **狀態二（滑落後）**：
  - 梯長仍然是 $2.5$ 公尺（斜邊不變！）
  - 梯頂下滑 $0.4$ 公尺 ➔ 新牆高 $b_2 = 2.4 - 0.4 = 2.0$ 公尺。
  - 新梯腳離牆底距離 $a_2 = \sqrt{2.5^2 - 2.0^2} = \sqrt{6.25 - 4.00} = \sqrt{2.25} = 1.5$ 公尺。（可聯想 $1.5 : 2.0 : 2.5 \implies 3 : 4 : 5$！）
- **求梯腳外移量**：
  $$\Delta a = a_2 - a_1 = 1.5 - 0.7 = 0.8 \text{ 公尺}$$

> 💡 **素養心智震撼**：
> 梯頂只下滑了 $0.4$ 公尺，梯腳卻向外滑動了 $0.8$ 公尺（整整 2 倍）！**這證明了梯子的滑動是非線性的！**

### 2. 折竹抵地（旗桿折斷觸地問題）
> **情境（取自《九章算術》）**：有一根高 16 公尺的旗桿，被強風從中吹折，旗桿頂端著地處距離旗桿底部 8 公尺，求旗桿折斷處離地面多少公尺？

**解題思考階梯**：
1. **設定未知數**：設折斷處離地面為 $x$ 公尺（垂直股長）。
2. **找出斜邊與另一股**：
   - 底部距離為 8 公尺（水平股長）。
   - 整根旗桿長 16 公尺，所以折斷倒下的部分長度為 $(16 - x)$ 公尺（斜邊）。
3. **依畢氏定理列方程式**：
   $$x^2 + 8^2 = (16 - x)^2$$
4. **展開乘法公式求解**：
   $$x^2 + 64 = 256 - 32x + x^2$$
   兩邊 $x^2$ 剛好相消！
   $$64 = 256 - 32x$$
   $$32x = 192 \implies x = 6$$
   故折斷處離地面 6 公尺（此時斜邊為 $16 - 6 = 10$，恰為 $6-8-10$ 經典直角三角形！）。

### 3. 現代素養：電視螢幕 16:9 對角線尺寸
> **情境**：常見的 16:9 寬螢幕電視，規格標示「65 吋」指的是螢幕對角線長度。請問該電視螢幕的長寬比例與真實幾何關係？

- 設寬為 $9k$，長為 $16k$。
- 對角線 $d = \sqrt{(16k)^2 + (9k)^2} = \sqrt{256k^2 + 81k^2} = \sqrt{337}k \approx 18.357k$。
- 因此只要已知對角線吋數，便能輕易解出 $k$，進而得知電視的精確長寬公分數。

## ⚠️ 常見易錯陷阱

> [!CAUTION]
> **陷阱：折竹問題將斜邊誤設為 $16 + x$ 或直接假設斜邊是 16！**  
> 旗桿不是倒在地上延伸，折斷後的兩段長度總和必須守恆等於原本總長 16！  
> 所以如果立著的是 $x$，倒下的斜邊必然是 $(16 - x)$！

## ✏️ 隨堂實戰練習

### 練習 1
一根長 10 公尺的梯子靠在垂直牆上，原本梯腳距牆 6 公尺。若要讓梯頂向上移動 2 公尺，梯腳必須向牆底推進多少公尺？
- **解答與思路**：
  1. 原牆高 $h_1 = \sqrt{10^2 - 6^2} = 8$ 公尺（$6-8-10$）。
  2. 梯頂向上移 2 公尺 ➔ 新牆高 $h_2 = 8 + 2 = 10$ 公尺。
  3. 新梯腳距牆底 $d_2 = \sqrt{10^2 - 10^2} = 0$ 公尺（梯子直立貼牆）。
  4. 梯腳需推進：$6 - 0 = 6$ 公尺。
