### 1. 含根式係數的一元一次方程式解法

解含根式的一元一次方程式，步驟與國一完全相同：**「未知數移左邊、常數移右邊、同除以係數、最後分母有理化」**！

$$A x = B \implies x = \frac{B}{A}$$
最後務必將 $\frac{B}{A}$ 化為**最簡根式**並**完成分母有理化**。

#### 示範：解方程式 $3\sqrt{8} x = 2\sqrt{3}$
- 第一步（化簡係數）：  
  $3\sqrt{8} = 3 \times (2\sqrt{2}) = 6\sqrt{2}$。  
  原式變為：$6\sqrt{2} x = 2\sqrt{3}$。
- 第二步（移項除以係數）：  
  $x = \frac{2\sqrt{3}}{6\sqrt{2}} = \frac{\sqrt{3}}{3\sqrt{2}}$。
- 第三步（分母有理化）：  
  $x = \frac{\sqrt{3} \times \sqrt{2}}{3\sqrt{2} \times \sqrt{2}} = \frac{\sqrt{6}}{3 \times 2} = \frac{\sqrt{6}}{6}$。

### 2. 學習與評量的界線原則（108 課綱核心精神）

在國中會考與段考中，教育部與臺師大心測中心（國中教育會考命題單位）有非常明確的「評量界線」規範，避免學生掉入無意義的繁瑣計算地獄：

> 🎯 **評量界線三大原則**：
> 1. **避免過度繁複的混合四則**：評量重點在於檢驗「根式概念理解、化簡能力與幾何直觀」，不考冷僻、多層重疊、計算量龐雜的技巧題。
> 2. **雙重根號不在國中範圍**：如 $\sqrt{4 + 2\sqrt{3}}$ 屬於高中數學課綱，國中評量嚴格不列入。
> 3. **重視估算與生活連結**：評量常以生活問題（如地毯邊長、螢幕對角線、斜邊距離）或數線上的位置評量數感。

## 二、 範例引導教學

### 📘 【範例 1：含根式的代數方程式（單項有理化標準題）】
**題目**：解方程式 $\sqrt{3}x - 5 = 7$。  
**思考階梯**：
- 第一步（常數項移至右邊）：  
  $\sqrt{3}x = 7 + 5 = 12$
- 第二步（兩邊同除以係數 $\sqrt{3}$）：  
  $x = \frac{12}{\sqrt{3}}$
- 第三步（單項式分母有理化，分子分母同乘 $\sqrt{3}$）：  
  $x = \frac{12\sqrt{3}}{3} = 4\sqrt{3}$。  
**答**：$x = 4\sqrt{3}$。

> 🌟 **高中銜接思考（選讀挑戰）**：  
> 若方程式為 $(\sqrt{3} - 1)x = 4$，則 $x = \frac{4}{\sqrt{3} - 1}$。此時需利用平方差公式，分子分母同乘 $(\sqrt{3} + 1)$ 消除分母根號，得 $x = 2\sqrt{3} + 2$。

---

### 📘 【範例 2：幾何生活應用題（幾何面積比）】
**題目**：有大小兩張正方形紙片，大正方形面積為 48 平方公分，小正方形面積為 12 平方公分。請問大正方形的邊長是小正方形邊長的幾倍？  
**思考階梯**：
- 第一步：求大正方形邊長：$\sqrt{48} = 4\sqrt{3}$ 公分。
- 第二步：求小正方形邊長：$\sqrt{12} = 2\sqrt{3}$ 公分。
- 第三步：相除求倍數：$\frac{4\sqrt{3}}{2\sqrt{3}} = 2$。  
  *(另解：面積比為 $48 : 12 = 4 : 1 \implies$ 邊長比為 $\sqrt{4} : \sqrt{1} = 2 : 1$！)*  
**答**：$2$ 倍。

## 三、 實戰梯度演練

### 基礎題（108 課綱與會考核心基礎）
1. 解下列方程式：  
   (1) $\sqrt{5} x = 10$  
   (2) $2\sqrt{3} x = \sqrt{18}$  
2. 直角三角形兩股長分別為 $2$ 與 $\sqrt{5}$，求斜邊長。

### 進階延伸挑戰題（🌟 運用平方差公式，選讀挑戰）
3. 解方程式 $(\sqrt{2} + 1)x = \sqrt{2} - 1$。
4. 某長方形長為 $(2\sqrt{3} + 1)$ 公分，面積為 $(7\sqrt{3} + 9)$ 平方公分，求此長方形的寬為多少公分？

---

### 📝 參考解答與解析
1. **答**：  
   (1) $x = \frac{10}{\sqrt{5}} = \frac{10\sqrt{5}}{5} = 2\sqrt{5}$。  
   (2) $x = \frac{\sqrt{18}}{2\sqrt{3}} = \frac{3\sqrt{2}}{2\sqrt{3}} = \frac{3\sqrt{6}}{6} = \frac{\sqrt{6}}{2}$。
2. **答**：$3$。（解析：由畢氏定理，斜邊 $= \sqrt{2^2 + (\sqrt{5})^2} = \sqrt{4 + 5} = \sqrt{9} = 3$）
3. **答**：$3 - 2\sqrt{2}$。  
   （解析：$x = \frac{\sqrt{2}-1}{\sqrt{2}+1} = \frac{(\sqrt{2}-1)^2}{(\sqrt{2}+1)(\sqrt{2}-1)} = \frac{2 - 2\sqrt{2} + 1}{2 - 1} = 3 - 2\sqrt{2}$）
4. **答**：$\sqrt{3} + 3$ 公分。  
   （解析：  
   $\text{寬} = \frac{7\sqrt{3} + 9}{2\sqrt{3} + 1} = \frac{(7\sqrt{3} + 9)(2\sqrt{3} - 1)}{(2\sqrt{3} + 1)(2\sqrt{3} - 1)} = \frac{42 - 7\sqrt{3} + 18\sqrt{3} - 9}{12 - 1} = \frac{33 + 11\sqrt{3}}{11} = 3 + \sqrt{3}$ 公分）
