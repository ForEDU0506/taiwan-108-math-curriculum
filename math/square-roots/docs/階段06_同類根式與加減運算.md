# 階段 6：同類根式與加減運算

## 一、 核心概念引導：什麼樣的根式才能相加減？

在國一學代數時，我們知道只有「同類項」才能合併：
$$2x + 3x = 5x \quad (\text{但 } 2x + 3y \text{ 不能合併})$$

根式的加減也是一模一樣的道理！

---

### 1. 同類根式（Like Radicals）的定義與判別

> **定義**：  
> 幾個根式**化為最簡根式後**，如果**根號內的數完全相同**，就稱為「**同類根式**」。

#### 🔍 經典辨別範例：
請問 $\sqrt{12}$ 與 $\sqrt{27}$ 是不是同類根式？
- 表面上看：一個是 12、一個是 27，看起來不一樣。
- **但先化為最簡根式**：
  $$\sqrt{12} = \sqrt{2^2 \times 3} = 2\sqrt{3}$$
  $$\sqrt{27} = \sqrt{3^2 \times 3} = 3\sqrt{3}$$
- 發現化簡後，根號裡面都是 $\sqrt{3}$！所以它們**是同類根式**，可以進行加減合併！

---

### 2. 同類根式的加減運算法則（分配律）

只有同類根式才能合併，利用乘法分配律提取公因式：
$$(a\sqrt{c}) \pm (b\sqrt{c}) = (a \pm b)\sqrt{c}$$

例如：
$$5\sqrt{2} + 3\sqrt{2} = (5 + 3)\sqrt{2} = 8\sqrt{2}$$
$$7\sqrt{5} - 2\sqrt{5} = (7 - 2)\sqrt{5} = 5\sqrt{5}$$

---

### 3. 先化簡、後合併的三步流程

面對多項根式的加減混合運算，請遵循黃金三步驟：
1. **第一步（化簡）**：把每一個根式各自化為最簡根式。
2. **第二步（分類）**：找出哪些是同類根式。
3. **第三步（合併）**：將同類根式的係數相加減，非同類根式照抄保持原樣。

---

## 二、 ⚠️ 致命迷思防範（全班最常錯的陷阱！）

> 🚨 **全台灣國中生最常犯的重大錯誤**：
> $$\sqrt{2} + \sqrt{3} \stackrel{?}{=} \sqrt{5} \quad (\text{\textbf{絕對錯誤！}})$$
> 
> 💡 **為什麼錯？數值驗證給你看**：
> - $\sqrt{2} \approx 1.414$
> - $\sqrt{3} \approx 1.732$
> - 左邊相加：$1.414 + 1.732 = 3.146$
> - 右邊 $\sqrt{5} \approx 2.236$！
> - $3.146$ 根本不等於 $2.236$！
> 
> **幾何意義反思**：  
> 一個面積為 2 的正方形邊長，加上一個面積為 3 的正方形邊長，兩段長度接起來，絕不等於面積為 5 的正方形邊長！  
> **牢記口訣**：**乘法可以把裡面乘起來，加法絕對不行把裡面加起來！**

## 三、 範例引導教學

### 📘 【範例 1：同類根式直接加減】
**題目**：計算下列各式：  
(1) $4\sqrt{3} + 7\sqrt{3} - 2\sqrt{3}$  
(2) $5\sqrt{2} + 3\sqrt{7} - 2\sqrt{2} + 4\sqrt{7}$  
**思考階梯**：
- (1) 全部都是 $\sqrt{3}$ 的同類項，直接係數相加減：  
  $(4 + 7 - 2)\sqrt{3} = 9\sqrt{3}$。
- (2) 分組整理同類項：  
  $\sqrt{2}$ 組：$(5 - 2)\sqrt{2} = 3\sqrt{2}$  
  $\sqrt{7}$ 組：$(3 + 4)\sqrt{7} = 7\sqrt{7}$  
  兩者非同類項不能再加，答案寫作 $3\sqrt{2} + 7\sqrt{7}$。  
**答**：(1) $9\sqrt{3}$；(2) $3\sqrt{2} + 7\sqrt{7}$。

---

### 📘 【範例 2：先化簡、後合併】
**題目**：計算 $\sqrt{12} - \sqrt{75} + \sqrt{48}$ 之值。  
**思考階梯**：
- 第一步：各自化為最簡根式：  
  $\sqrt{12} = \sqrt{4 \times 3} = 2\sqrt{3}$  
  $\sqrt{75} = \sqrt{25 \times 3} = 5\sqrt{3}$  
  $\sqrt{48} = \sqrt{16 \times 3} = 4\sqrt{3}$
- 第二步：全部都是 $\sqrt{3}$，合併係數：  
  原式 $= 2\sqrt{3} - 5\sqrt{3} + 4\sqrt{3} = (2 - 5 + 4)\sqrt{3} = 1\sqrt{3} = \sqrt{3}$。  
**答**：$\sqrt{3}$。

---

### 📘 【範例 3：含分數有理化的加減】
**題目**：計算 $\sqrt{18} - \frac{4}{\sqrt{2}}$ 之值。  
**思考階梯**：
- 第一項化簡：$\sqrt{18} = \sqrt{9 \times 2} = 3\sqrt{2}$。
- 第二項分母有理化：$\frac{4}{\sqrt{2}} = \frac{4\sqrt{2}}{2} = 2\sqrt{2}$。
- 同類項相減：$3\sqrt{2} - 2\sqrt{2} = (3 - 2)\sqrt{2} = \sqrt{2}$。  
**答**：$\sqrt{2}$。

## 四、 實戰梯度演練

### 基礎題
1. 計算下列各式：  
   (1) $3\sqrt{5} + 8\sqrt{5}$  
   (2) $9\sqrt{6} - 12\sqrt{6} + 4\sqrt{6}$  
2. 計算 $\sqrt{20} + \sqrt{45}$ 之值。
3. 計算 $\sqrt{50} - \sqrt{32} + \sqrt{8}$ 之值。

### 進階題
4. 計算 $\sqrt{27} + \frac{6}{\sqrt{3}} - \sqrt{12}$ 之值。
5. 化簡 $2\sqrt{24} - \sqrt{\frac{2}{3}} + \sqrt{54}$。

---

### 📝 參考解答與解析
1. **答**：  
   (1) $(3 + 8)\sqrt{5} = 11\sqrt{5}$。  
   (2) $(9 - 12 + 4)\sqrt{6} = \sqrt{6}$。
2. **答**：$5\sqrt{5}$。（解析：$\sqrt{20} = 2\sqrt{5}$，$\sqrt{45} = 3\sqrt{5}$，原式 $= 2\sqrt{5} + 3\sqrt{5} = 5\sqrt{5}$）
3. **答**：$3\sqrt{2}$。（解析：$5\sqrt{2} - 4\sqrt{2} + 2\sqrt{2} = (5 - 4 + 2)\sqrt{2} = 3\sqrt{2}$）
4. **答**：$3\sqrt{3}$。（解析：$\sqrt{27} = 3\sqrt{3}$；$\frac{6}{\sqrt{3}} = \frac{6\sqrt{3}}{3} = 2\sqrt{3}$；$\sqrt{12} = 2\sqrt{3}$。原式 $= 3\sqrt{3} + 2\sqrt{3} - 2\sqrt{3} = 3\sqrt{3}$）
5. **答**：$\frac{41\sqrt{6}}{6}$。（解析：$2\sqrt{24} = 4\sqrt{6}$；$\sqrt{\frac{2}{3}} = \frac{\sqrt{6}}{3}$；$\sqrt{54} = 3\sqrt{6}$。原式 $= 4\sqrt{6} + 3\sqrt{6} - \frac{\sqrt{6}}{3} = 7\sqrt{6} - \frac{1}{3}\sqrt{6} = \frac{20}{3}\sqrt{6} = \frac{40\sqrt{6}}{6}$ 或 $\frac{20\sqrt{6}}{3}$）
